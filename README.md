# Projects

A collection of projects developed by **Dominex Macedon**.

| Project | Description |
|---|---|
| [Puma](https://github.com/dominexmacedon-docs/puma) | A programming language and runtime for building applications with `.pulsar` source files. |
| [Puma Programming Language](https://github.com/dominexmacedon-docs/puma-programming-language) | The main Puma programming language implementation, including its lexer, parser, evaluator, and runtime. |
| [Puma Data for AI Models](https://github.com/dominexmacedon-docs/puma-data-for-ai-models) | Dataset and training resources containing Puma programming examples for AI code intelligence. |
| [greenServe](https://github.com/dominexmacedon-docs/greenServe-lang) | A C-based programming language specially built for server implementation. |
| [greenServe Modules](https://github.com/dominexmacedon-docs/greenServe-modules) | C-based shared modules (`.so`) extending greenServe with additional functionality. |
| [CMLL](https://github.com/dominexmacedon-docs/CMLL) | A programming language project focused on configuration, automation, and system-oriented development. |

## About

These repositories represent programming languages, runtimes, modules, and AI-related developer resources created by **Dominex Macedon**.
